# Support for Deucarian Bootstrap

Use [GitHub Issues](https://github.com/Deucarian/Bootstrap/issues) for reproducible first-time setup, repair, fallback-catalog, or bootstrap editor-UI defects; documentation gaps; and narrowly scoped feature requests. Search existing issues before opening a new one.

Include the bootstrap version, Unity editor version and operating system, selected channel, clean-project or repair context, the smallest reproduction, and the complete editor error with local paths, tokens, and private repository data removed.

`main` is the stable package channel. `develop` is a preview channel and may change before promotion. Please reproduce against the applicable current channel before reporting an older snapshot.

Do not disclose vulnerabilities, registry credentials, private repository URLs, or user data in an issue. Follow [SECURITY.md](SECURITY.md) for private security reports.

Support is provided on a best-effort basis. Package Installer and individual package defects belong in their owning repositories; Unity Package Manager defects outside Bootstrap are owned by Unity.
